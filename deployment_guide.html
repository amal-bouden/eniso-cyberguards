1 Clone & Pull Latest Code

Ensure you are working with the latest commits on the main branch:

# Clone repository (or pull latest)
git clone https://github.com/amal-bouden/eniso-cyberguards.git
cd eniso-cyberguards
git checkout main
git pull origin main
npm install

2 Setup Cloud Database (Turso / LibSQL)

In serverless environments like Vercel, local SQLite files are read-only and ephemeral. The platform is configured to use Turso (Serverless SQLite over HTTP/WebSocket via @libsql/client).

Option A: Fast Turso CLI (2 minutes):

# Install Turso CLI:
# Windows (PowerShell): irm https://get.tur.so/install.ps1 | iex
# macOS / Linux: curl -sSfL https://get.tur.so/install.sh | bash

# Login and create database:
turso auth login
turso db create eniso-ctf-prod

# Get the Database URL:
turso db show eniso-ctf-prod --url
# Output format: libsql://eniso-ctf-prod-[your-org].turso.io

# Generate permanent Auth Token:
turso db tokens create eniso-ctf-prod
# Copy the JWT string generated

Option B: You can also use the web UI at https://turso.tech (sign in with GitHub > Create Database > Generate Token).

3 Environment Variables Configuration

Create a local .env file (and set these inside the Vercel Project Settings):

# 1. Database Connection (Turso)
DATABASE_URL="libsql://eniso-ctf-prod-[your-org].turso.io"
TURSO_DATABASE_URL="libsql://eniso-ctf-prod-[your-org].turso.io"
TURSO_AUTH_TOKEN="eyJhbGciOi..."

4 One-Click Database Seeding

A standalone seed script (scripts/seed-production.cjs) is included. It connects directly via the LibSQL client, creates all tables, and provisions the admin and challenge catalog: 

# Run standalone seed script (requires TURSO_DATABASE_URL & TURSO_AUTH_TOKEN in .env)
node scripts/seed-production.cjs
✅
What is automatically created:
  • All SQL Tables: User, Challenge, Solve, InviteCode.
  • All 9 CTF Challenges with flags, points, hints, categories, and instance URLs.
  • Default Admin Account: FLUTTERSHY (boudenammal02@gmail.com).
  • Active Invite Codes: SPARTAN-2026-CTF (100 uses) and ENISO-JOIN-2026 (50 uses).

5 Deploying to Vercel

Follow these steps to deploy on Vercel:

  • Log in to https://vercel.com and click Add New Project.
  • Import Git repository: amal-bouden/eniso-cyberguards.
  • Framework Preset: Next.js (automatically detected).
  • Build Command: Leave default or ensure it runs prisma generate; next build (already configured in package.json).
  • Add Environment Variables under Project Settings > Environment Variables:
Variable Name Description Example / Value Required
DATABASE_URL Turso DB URL libsql://eniso-ctf-prod-*.turso.io Yes
TURSO_DATABASE_URL LibSQL URL Same as DATABASE_URL Yes
TURSO_AUTH_TOKEN Turso JWT Token eyJhbGciOi... Yes
JWT_SECRET Auth Session Secret 64-char random hex string Yes
SETUP_CODE Emergency Admin Setup CYBERGUARDS-ADMIN-SETUP-2026 Yes 
# Or deploy via Vercel CLI from repository root:
npm install -g vercel
vercel --prod

7 Troubleshooting & Tips

💡
Prisma on Vercel Linux: Commit 6812aad already configured binaryTargets = ["native", "rhel-openssl-1.0.x", "rhel-openssl-3.0.x", "linux-musl"] in prisma/schema.prisma, preventing binary mismatch errors during Vercel builds.
💡
Auto-Initialization: The platform features an automatic self-initializing hook in lib/db-auto-init.ts. If the database is connected but empty, the application will automatically create the tables and seed the challenges on the first page request.
